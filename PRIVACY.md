# Privacy Policy for FACEIT Rating

FACEIT Rating is a Chrome extension that displays FACEIT Rating badges inside FACEIT CS2 matchrooms.

## Data the extension uses

The extension may read content on FACEIT CS2 matchroom pages in order to identify player rows and display rating badges next to the correct players.

The extension sends the FACEIT matchroom ID to a backend API in order to retrieve public matchroom roster and player information.

The extension may request public FACEIT statistics from FACEIT endpoints in order to calculate and display FACEIT Rating information.

## Data the extension does not collect

FACEIT Rating does not collect, sell, rent, or trade personal user data.

The extension does not collect:

* passwords
* payment information
* health information
* private messages
* emails
* browsing history
* keystrokes
* precise location data

## Local settings

User preferences such as compact mode, colored tiers, progress bar, and best-player star are stored locally in Chrome using `chrome.storage.local`.

## Backend API

The backend API is used only to retrieve FACEIT matchroom roster/player data required for the extension’s single purpose.
